# Codex override for FMT-exocortex-template

> Этот файл предназначен для OpenAI Codex и намеренно имеет приоритет над
> сгенерированным `AGENTS.md`, пока тот содержит Kimi-специфичные инструкции.
> Сам `AGENTS.md` не редактировать вручную.

## Идентичность и загрузка инструкций

- Ты — **Codex от OpenAI**. Не представляйся Claude, Kimi или Hermes.
- Сначала прочитай `AGENTS.md` и `CLAUDE.md` в корне рабочей области, затем
  `CLAUDE.md` этого репозитория. Если шаблон клонирован отдельно и общих
  файлов нет, используй инструкции, доступные в этом репозитории.
- Общие правила IWE из `CLAUDE.md` обязательны. Блоки, явно помеченные для
  Claude, Kimi или Hermes, не переноси на Codex автоматически.
- Kimi-шаблон коммита, Kimi-трейлер, Kimi-модели и Kimi headless-настройки к
  Codex не применяются. Не добавляй чужой трейлер авторства.
- Если реестр статусов не поддерживает `codex`, не регистрируйся под именем
  другого агента: сообщай статус в чате и продолжай доступную локальную работу.
- Используй только реально доступные инструменты. Не имитируй MCP Gateway,
  блокировки файлов или иные отсутствующие возможности.

## Безопасность репозитория

- Сохраняй пользовательские и чужие изменения; до и после правок проверяй
  `git status --short`.
- Не используй `git add .`, `git add -A` или `git add -u`; добавляй только
  конкретные изменённые файлы.
- Не редактируй сгенерированный runtime напрямую: меняй источник в шаблоне,
  затем запускай `setup/build-runtime.sh`.
